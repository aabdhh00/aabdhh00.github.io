Privacy policy

Last updated: 5 October 2026

Who uses this app

Message Monitor is a personal tool used only by its owner, with the owner's own Google accounts. It is not offered to anyone else.

What data it accesses

  • Gmail: reads incoming messages to sort them, find tasks and deadlines, and summarize them. It may add labels. It never deletes email. It sends summary emails from the owner's account.
  • Google Calendar and Google Tasks: may create events and tasks for the owner's own reminders.

How the data is used and stored

Data is used only to provide these features to the owner. It is stored in a private database that only the owner can access. Message text may be sent to an AI service to sort and summarize it; that service does not use it to train models.

Data is not sold, shared with advertisers, or used for any other purpose.

Google API Services User Data Policy

Message Monitor's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account → Third-party connections. Stored data is deleted on request.

Contact

Use the support email shown on the app's Google sign-in screen.
